## what

Installed various development utilities, media players, and system management packages (`zola`, `corepack`, `mpv`, `ncdu`, `pavucontrol`).

## why

- **zola (2026-06-02):** Fast static site engine used to build and preview markdown-based blogs locally.
- **corepack (2026-06-03):** Node.js manager bridge to provision explicit wrapper binaries for `pnpm` and `yarn`.
- **mpv (2026-06-05):** Keyboard-driven media player that integrates cleanly inside tiling window managers.
- **ncdu (2026-05-19):** NCurses terminal disk utility used to visually audit and clear storage space leaks.
- **pavucontrol (2026-05-02):** PulseAudio graphic management panel to route sound server streams and hardware channels.

## Command

```bash
sudo pacman -S zola corepack mpv ncdu pavucontrol
```
