# i3 keybindings

## layout modes

* `Mod + h` → split horizontal
* `Mod + v` → split vertical
* `Mod + e` → toggle split (tiling)
* `Mod + s` → stacked layout
* `Mod + w` → tabbed layout

---

## resizing mode

* `Mod + r` → enter/exit resize mode

inside resize mode:

* `← / →` → resize
* `j / ;` → resize

---

## moving focus

* `Mod + ← / →`
* `Mod + j / ;`

---

## moving windows

* `Mod + Shift + ← / →`
* `Mod + Shift + j / ;`

---

## reload / exit

* `Mod + Shift + c` → reload config
* `Mod + Shift + r` → restart i3 (in-place)
* `Mod + Shift + e` → exit i3

---

## notes

* `Mod` = Super / Windows key
* arrows and `j/;` are interchangeable
