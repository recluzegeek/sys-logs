-- i3wm modes
win + h => horizontal split
win + v => vertical split
win + e => tiling mode
win + s => stacked windows
win + w => tabbed mode

-- resizing windows
win + r => enter/exit the resize mode
    use either left/right arrows to resize windows
    or j and ; keys to resize

-- moving windows
win + <left/right arrows> or
win + <j/;> keys

-- switching the windows
win + shift + <left/right arrows> or
win + shift + <j/;> keys

-- reload keys
win + shift + c => reloads the config file
win + shift + r => restart i3 in place, i3wm upgrade
win + shift + e => i3wm exit
